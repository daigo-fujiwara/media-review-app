## 主な機能
- **WANTリスト**: 観たい映画や読みたい本をクイックに登録。
- **DONEリスト**: レビューと評価（5段階）を記入してアーカイブ。
- **クイックレビュー**: WANTリストを経由せず、いきなりレビューを投稿することも可能。

## 技術スタック
- Java 17
- Spring Boot 3
- Spring Data JPA
- H2 Database
- Thymeleaf / Bootstrap 5
